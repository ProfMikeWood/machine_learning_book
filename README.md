# Machine Learning

This book is designed to provide an introduction to machine learning with PyTorch and Scikit-Learn. It was been first designed for a CS 171 course at San Jose State University and later used in a MS 285 Machine Learning Application in Marine Science course at the Moss Landing Marine Labs. It is still a work in progress! Please don't hesitate to submit a pull requrest to update the contents if you have any valuable contributions.

The key parts of this repository are as follows:
1. Notes provided as a git book
2. Data and images to support the notebooks

To access the book in HTML format, click [HERE](https://profmikewood.github.io/machine_learning_book/).
